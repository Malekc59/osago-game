# 🚗 Умный водитель с ОСАГО

**3D-аркада от первого лица про вождение и расчёт полиса ОСАГО**

> Пройди 10 заездов, избегай аварий и снизь стоимость полиса до минимума!

---

## 🎮 Описание игры

«Умный водитель с ОСАГО» — это браузерная 3D-аркада, в которой игрок садится за руль виртуального автомобиля и проезжает 10 заездов по меняющимся ландшафтам: лес, поле, город.

Каждая авария повышает коэффициент КБМ и удорожает виртуальный полис ОСАГО. Чем меньше аварий — тем дешевле полис. Цель: дойти до 10-го заезда с минимальным КБМ.

### Особенности:
- 🏎️ **Вид от первого лица** с вращающимся рулём
- 🌲 **3 ландшафта**: лес, поле, город
- 🎚️ **Реальный расчёт КБМ** по формулам ОСАГО
- 🛒 **Магазин**: бусты, премиум-тачки, VIP-подписка
- 📱 **Работает на телефоне и компьютере**

## 🚀 Как запустить

### Вариант 1: GitHub Pages (уже работает)
Открой в браузере: `https://malekc59.github.io/osago-game/`

### Вариант 2: Локально
1. Скачай репозиторий
2. Открой `index.html` в браузере
3. Для корректной работы рекомендуется запускать через локальный сервер:
   ```bash
   npx serve .
   # или
   python -m http.server 8000
   ```

## 🎯 Геймплей

### Управление
| Действие | Компьютер | Телефон |
|----------|-----------|---------|
| Влево | ← или A | Тап левой половины экрана |
| Вправо | → или D | Тап правой половины экрана |
| Газ | ↑ или W | Автоматически |
| Тормоз | ↓ или S | — |
| Пауза | ESC или P | — |

### Прогрессия
- Игра начинается с **3 класса КБМ** (коэффициент 1.0)
- Нужно пройти **10 заездов**
- Каждая авария повышает КБМ и удорожает полис
- После 10-го заезда показывается итоговый результат

### Расчёт полиса
```
Полис = 3000 ₽ × город × мощность × КБМ
```

| Город | Коэффициент |
|-------|-------------|
| Москва | 0.8 |
| Санкт-Петербург | 1.0 |
| Екатеринбург | 1.2 |
| Другой | 1.5 |
