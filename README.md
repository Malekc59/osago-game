# 🚗 Умный водитель с ОСАГО 3D

HTML5-аркада от первого лица про вождение и систему КБМ (коэффициент бонус-малус) ОСАГО.

## 🎮 Описание

- **Жанр:** 3D-аркада / endless runner
- **Платформа:** Яндекс.Игры (HTML5)
- **Монетизация:** Реклама (fullscreen, rewarded video) + внутриигровые покупки
- **Целевая аудитория:** Водители РФ, пользователи Яндекса

## 🚀 Как запустить локально

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

Откройте `http://localhost:8000`

## 🎯 Механика

1. Выбирай город регистрации и мощность авто — влияет на базовую цену полиса
2. Проезжай 10 заездов, уклоняясь от машин и препятствий
3. Чем меньше аварий за сезон — тем выше класс водителя и ниже КБМ
4. Класс растёт от 3 (КБМ 1.0) до 13 (КБМ 0.50)
5. Очки = сэкономленные рубли относительно базовой цены

## 💰 Монетизация

| Тип | Реализация |
|-----|-----------|
| Fullscreen-реклама | Между заездами |
| Rewarded video | Отмена аварии |

## 🔌 SDK Яндекс.Игры

- `YaGames.init()` — инициализация
- `LoadingAPI.ready()` — сигнал о загрузке
- `GameplayAPI.start()/stop()` — начало/конец игрового процесса
- `adv.showFullscreenAdv()` — полноэкранная реклама
- `adv.showRewardedVideo()` — реклама за награду
- `getPayments()` — внутриигровые покупки
- `getLeaderboards()` — таблица лидеров
- `getPlayer().setData()/getData()` — облачные сохранения
