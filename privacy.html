Политика конфиденциальности

Дата последнего обновления: 6 августа 2026 г.

1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») описывает, как мини-приложение «ОСАГО: Умный водитель» (далее — «Приложение») обрабатывает данные пользователей.

1.2. Используя Приложение, Пользователь выражает согласие с условиями настоящей Политики.

2. Какие данные мы собираем

2.1. Приложение не собирает персональные данные Пользователей.

2.2. Единственные данные, которые сохраняются на устройстве Пользователя:

  • лучший игровой результат (число);
  • количество сыгранных игр (число);
  • общее количество аварий (число).

2.3. Указанные данные хранятся исключительно в локальном хранилище браузера (localStorage) и не передаются на серверы администрации или третьим лицам.

3. Как мы используем данные

3.1. Данные из localStorage используются исключительно для отображения статистики внутри Приложения.

3.2. Приложение не использует cookies, веб-маяки или аналитические скрипты для отслеживания Пользователей.

4. Передача данных третьим лицам

4.1. Приложение не передаёт данные Пользователей третьим лицам.

4.2. Приложение не интегрировано с внешними аналитическими сервисами, рекламными сетями или социальными сетями (кроме платформы VK, в рамках которой оно функционирует).

5. Хранение и удаление данных

5.1. Данные хранятся на устройстве Пользователя до тех пор, пока он не очистит локальное хранилище браузера.

5.2. Пользователь может удалить все сохранённые данные, очистив кэш и данные сайта в настройках браузера.

5.3. Администрация не имеет технической возможности удалить данные с устройства Пользователя удалённо.

6. Безопасность

6.1. Приложение размещено на защищённом хостинге GitHub Pages с использованием протокола HTTPS.

6.2. Администрация принимает разумные меры для защиты данных, но не может гарантировать абсолютную безопасность передачи данных через интернет.

7. Изменение политики

7.1. Администрация оставляет за собой право вносить изменения в настоящую Политику.

7.2. Новая редакция Политики вступает в силу с момента её размещения по адресу, указанному в Приложении.

8. Контактная информация

По вопросам, связанным с обработкой данных, Пользователь может обратиться через сообщения сообщества ВКонтакте.
